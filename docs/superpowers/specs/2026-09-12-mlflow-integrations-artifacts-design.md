# MLflow 集成接入与受控产物设计

用户已批准下一轮目标：外部系统以独立身份创建实验、记录结果、上传模型产物，平台负责人可查看下载，其他身份访问被拒绝。本轮不启动训练、评估或推理服务。

## 身份与授权

采用独立身份表、令牌表和实验授权表。机器 HTTP 主体始终为 `integration:<id>`，不继承负责人的角色、个人存储根或交互登录能力。令牌复用现有摘要认证机制和 `rpt_` 格式，但通过独立记录查找；旧 PAT、训练接口、SDK 六方法合同保持兼容。每次认证核对身份、令牌、负责人账号、当前团队 membership 和团队生命周期；失效后拒绝访问。

交互登录用户仅管理自己在当前团队创建的集成，设置是否允许创建实验，签发 1–30 天令牌，授权指定的本人实验，撤销凭据或身份。令牌仅创建时返回，数据库不存明文。最多 20 个身份、每身份 20 个有效凭据、100 个实验授权。权限为实验 read/write 与 artifacts:read/write；scope 与资源授权同时满足才放行。机器路由采用封闭名单，不能访问旧 jobs、Ray、个人数据、调试、成员或令牌管理接口。

现有 MLflow service 保留原有归属和租约逻辑，外层授权适配器在验证 grant 后才委派负责人 actor。HTTP principal 和审计仍为机器身份。创建幂等键按集成身份分域，分页游标绑定集成和查询，列表按当前授权过滤。允许创建的实验自动授予该集成权限，负责人可查看产生的资源；重复创建不能恢复已撤销的 grant。拒绝直接把机器 HTTP 主体改成负责人，这会让旧业务接口继承过多权限。

## 产物

产物是外部 Run 下的独立不可变记录，包含文件名、大小、SHA-256、状态、上传分片进度、创建时间。不解压、不加载模型，不移动或删除用户个人文件。存储固定在 `raytrain-mlflow-artifacts/{artifactID}/parts/{index}`，客户端不能提供 bucket、任意对象键或路径。

REST 上传分为初始化、固定 8 MiB 分片、完整校验、取消。单文件最多 20 GiB；每团队/负责人预留与完成文件合计 100 GiB，最多 16 个未完成上传。预算由数据库事务预留，不能靠客户端声明绕过。分片大小及摘要由服务端验证；同一分片同内容重试幂等，不同内容冲突。完成后顺序流式核对所有分片、总大小及总 SHA-256，只有 READY 能下载；READY 不可覆盖。上传应在 Run 结束前完成。

同产物变更串行化，锁等待有上限；完整校验有 15 分钟硬超时，可能占用一个数据库连接，超时仍可重试。不会持有负责人预算锁等待大文件网络 IO。上传有效期 24 小时，过期不继续写；可取消释放预算，但只有本产物对象清理成功才释放。未完成记录不会被当作可用模型。

下载每次按当前 Run 和 grant 重新鉴权，返回 attachment、no-store、nosniff，文件数据按序流式输出，不向客户端交付存储密钥或永久直链。平台产物不自动写入原生 MLflow 共享目录；原生 MLflow 共享管理边界保持如实标注。

## 页面与接口

实验中心增加“集成接入”子页，管理身份、短期令牌和实验授权。外部 Run 详情增加产物列表及已完成文件下载，显示明确状态和失败原因。仍保留 11 个一级菜单。本轮上传由外部程序 REST 完成，SDK 仍为六方法子集。

管理接口为 `/api/v1/mlflow/integrations` 及其 tokens/grants 子资源；产物接口位于 `/api/v1/mlflow/runs/{runId}/artifacts`。旧接口字段保持兼容，新增能力通过 capabilities 明确披露。

## 发布和验收

新表使用连续迁移 47、48，不修改既有个人数据归属、训练记录或 GPU 配额。发布前备份并隔离恢复 schema 46 数据，验证新装、重复执行和带旧数据升级；旧后端必须能读取升级后数据库。仅构建 backend，Portal 从独立 dev 通过自身 CI 发布。

验收覆盖机器路由越权、同负责人不同集成隔离、scope/grant 撤销、owner membership 失效、幂等键与游标隔离；上传大小/路径/摘要错误、重复分片、并发完成与取消、预算竞争、恢复与下载一致性。保留现有训练 UID/状态/重启数证据。生产仅使用明确标识的短期验收身份与专用实验/文件，结束后撤销测试凭据。实际对接方身份与秘密交付渠道尚未指定，不向他人发送令牌。
