# 个人空间根目录入口设计

## 目标

在“我的数据”页提供一个可直接浏览的“我的文件”根目录 `/mnt/storage/me`，不再额外嵌套两个入口卡片。

## 设计

- 后端新增稳定逻辑空间 `my-storage`，根前缀就是当前用户的个人对象存储根，Pod 路径为 `/mnt/storage/me`。
- “我的数据”只展示一个“我的文件”卡片；点击后，下方现有文件浏览器直接浏览该根目录。
- `my-files` 与 `my-runs` 继续保留给历史任务、输出目录和滚动发布兼容，但新页面不重复展示。
- 新任务选择个人训练输入时使用 `my-storage`，目录相对于个人根解析，不再隐式添加 `files/`。
- 训练输出仍受控写入 `my-runs`，即 `/mnt/storage/me/runs`；`/workspace` 继续作为独立代码工作区。

## 验收

- 后端测试确认 `my-storage` 只访问当前用户根前缀，并可作为受控训练输入。
- 页面测试确认只显示一个直接根入口，且旧目录在后端滚动期间仍可回退使用。
- 前端完整测试通过。
- 前端生产构建通过。
