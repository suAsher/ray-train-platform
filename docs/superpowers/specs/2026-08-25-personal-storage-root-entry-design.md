# 个人空间根目录入口设计

## 目标

在“我的数据”页明确展示调试与训练环境中的个人读写根目录 `/mnt/storage/me`，并让用户能够直接进入“我的文件”和“我的运行结果”。

## 设计

- 在数据空间卡片列表上方增加“个人空间”总览卡。
- 总览卡展示 `/mnt/storage/me`，并说明它是 Pod 内的个人读写根目录。
- 卡片展示并可进入两个受控分区：
  - `/mnt/storage/me/files` → 我的文件
  - `/mnt/storage/me/runs` → 我的运行结果
- 不新增后端数据空间 ID，不允许网页直接枚举或写入个人根目录，以免绕过现有的文件、结果目录边界。
- `/workspace` 继续作为独立的代码工作区展示，不并入本卡片。

## 验收

- 页面源码回归测试确认三个路径和两个分区入口均存在。
- 前端完整测试通过。
- 前端生产构建通过。
