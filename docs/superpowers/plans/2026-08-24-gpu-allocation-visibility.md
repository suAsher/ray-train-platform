# GPU Allocation Visibility Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Show exactly which user and team owns every active training or interactive-debug GPU allocation.

**Architecture:** Add a repository-backed, role-scoped read API that projects active jobs and workspaces into one immutable allocation model. Consume that endpoint in the existing compute overview and admin queue screens while preserving the current training cancellation flow.

**Tech Stack:** Go, Gin, GORM/PostgreSQL, Vue 3, Element Plus, Node test runner.
