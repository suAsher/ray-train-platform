指标：VMCluster + 独立 Grafana HA

VMAgent 双副本抓取基础设施、组件及后端 HTTP 指标，业务数据写入 VMCluster tenant 1001。独立 Grafana 两副本共享 PostgreSQL 三副本，由专用 CNPG Operator 双副本管理；已接通 VM、原 Prometheus、Loki、ClickHouse 四个数据源。旧 Grafana 与自建看板保留，临时 HTTPS 31701 已切换到新 Grafana 并完成验收；旧账号与自建配置未自动迁移。

日志：原有用户体验持续保留

Alloy 两副本通过 Kubernetes API 分片采集，Loki 三副本与上海 TOS 保存平台日志。新增指标由 VMAgent 采集；HTTP 请求事件由后端直接发往 OTel。扩展体系不会把全部新信号压到 Alloy，也不会用 ClickHouse 替换训练日志查询。

HTTP 追踪、分析与统一告警

后端通过 mTLS OTLP HTTP 14318 导出请求 spans / events；OTel 双副本使用持久队列，ClickHouse 为 1 shard × 2 replicas、3 Keeper，logs 保留 7 天、traces / lookup 30 天。HTTP 接入已验收；仅覆盖 HTTP 边界，异步 Worker / 全任务追踪尚未接入。夜莺 HTTPS 31700 可配置告警，通知渠道由用户在 UI 配置。
